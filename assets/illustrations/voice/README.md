# Ilustraciones de acciones de atención al cliente

Generadas con la herramienta integrada `image_gen`, con fondo transparente. Optimizadas a WebP conservando el canal alfa. Son ilustraciones explicativas, no imágenes de clientes ni capturas de un servicio real.

Se muestran dentro de la escena interactiva al seleccionar consulta, cita o incidencia. Las imágenes tienen dimensiones reservadas y dos tamaños de entrega: 256 y 512 píxeles.
